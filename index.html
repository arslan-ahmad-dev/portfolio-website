2024 — Present

Amazon / Walmart Repricer

Automated Repricing Engine for Amazon & Walmart Marketplace Sellers

Python Django Celery Redis PostgreSQL Amazon API Walmart API

Overview

A full-featured, intelligent repricing platform built for Amazon and Walmart marketplace sellers to automate and optimize their pricing strategies at scale. The system continuously monitors competitor pricing, BuyBox status, and market conditions to adjust prices in real time — maximizing profit margins while staying competitive.

Key Contributions

  • Designed and built the core repricing engine supporting multiple pricing strategies — including min/max price boundaries, BuyBox-targeted repricing, and custom rule-based logic tailored to individual seller goals.
  • Implemented one-to-one and bulk strategy assignment, allowing sellers to apply repricing rules to individual SKUs or across thousands of products simultaneously with a single action.
  • Built a real-time BuyBox monitoring system that tracks competitor prices and ownership changes, triggering instant repricing adjustments to win or maintain the BuyBox.
  • Engineered min price and max price guardrails to protect seller margins — ensuring automated repricing never goes below cost or above market tolerance.
  • Developed a robust strategy management module where sellers can create, edit, duplicate, and prioritize multiple repricing strategies across their entire catalog.
  • Optimized background task processing with Celery and Redis to handle high-volume repricing cycles across large inventories without performance degradation.
  • Integrated directly with the Amazon SP-API and Walmart Seller API for real-time price updates, inventory sync, and order data ingestion.

Impact

Became the core product of the business — enabling sellers to automate pricing decisions that previously required hours of manual monitoring, directly increasing BuyBox win rates and revenue for users across the platform.

Ah-Scrapers

Enterprise Web Scraping Pipeline for Amazon Arbitrage

Python Scrapy Redis Docker PostgreSQL Celery

Overview

Ah-Scrapers is a production-grade, distributed web scraping pipeline designed to extract and clean data from multiple e-commerce platforms to identify profitable Amazon arbitrage opportunities. The system powers real-time product discovery and pricing intelligence across competing marketplaces.

Key Contributions

  • Architected a scalable scraping pipeline capable of handling millions of product pages, significantly improving profitability and operational efficiency.
  • Implemented an intelligent data cleaning layer that removes noise and standardizes scraped data into a consistent format ready for downstream analysis.
  • Built a robust data validator that guarantees accuracy and reliability of extracted records, preventing bad data from entering production systems.
  • Designed custom middleware for intelligent request/response handling, rotating proxies, and user-agent management — drastically reducing block rates on target sites.
  • Extended the pipeline with new features including additional e-commerce integrations and advanced data analysis dashboards.
  • Leveraged Redis for distributed task queuing, deduplication, and high-speed caching.
  • Containerized the entire stack with Docker for reproducible deployments across staging and production.

Impact

The system became a core part of the business intelligence stack, processing large volumes of product data daily and enabling data-driven purchasing decisions.
